# BPM Music Match

A mobile-web prototype that turns manually tapped workout cadence into a continuous percussion rhythm and then crossfades that rhythm into one controlled audio track.

## Current scope

The first milestone proves one true crossfade using a single raw Web Audio graph. It deliberately excludes music-provider integration, catalog/search, accounts, a backend, and generalized BPM matching.
